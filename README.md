# Индивидуальный проект информационная система "Студия звукозаписи Gao's Studio"

## Перед запуском

1. Запустить XAMPP (рекомендуется версия 3.3.0 или выше)  
2. Включить Apache  
3. Включить MySQL  
4. Скачать файл `rec_studio.sql`  
5. Открыть phpMyAdmin  
6. Импортировать скачанный файл

## Для запуска 
1. Запустить XAMPP (рекомендуется версия 3.3.0 или выше)  
2. Включить Apache  
3. Включить MySQL
4. Открыть в браузере ссылку http://localhost/Rec_studio/index.php
